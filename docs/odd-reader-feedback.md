# ODD reader feedback

The left list wraps full document names and paginates by available body rows.
Arrow keys page the list; `j`/`k` or up/down walk across page boundaries. Tab does
not switch an ODD-only reader to another dataset.

Search uses `T`; its hint belongs only in the single footer row. While search is
active, Delete clears the whole query and Backspace deletes one character. The
footer advertises clearing only in that mode. Escape leaves search before closing
the reader. Existing preview scroll, opener and refresh actions remain available.

The reader does not write worktree associations. Tests retain readonly controls,
filter persistence, mouse input, frame widths and pagination without skipped
names. Keyboard-byte replay is not a claim of physical-terminal verification.
